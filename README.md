# toggle-init-vis-vscode

__init__.py files are annoying.

This VS Code extension adds a simple command toggle-init-files to toggle the visibility of python __init__.py files in explorer.


**Default MacOS keybind:** `cmd+shift+i`

**Default Windows keybind:** `ctrl+shift+i`


Default binds might overlap with Cursor's 'AI Pane' bindings. Easy change in Code settings if so.
